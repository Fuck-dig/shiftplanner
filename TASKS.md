- [x] ~~Fix an email being sent to the manager on every login; unclutter the notification bell~~ (2026-08-03) - severity 6/10 - REAL BUG. The three manager-email effects seed a "already seen" set on first run so only things arriving AFTER the session starts get emailed. But they seeded from whatever state held at that moment, and myEmail comes straight off the auth session while time off/swaps/replies arrive from a later fetch - so the seed ran against an empty array, and every existing pending item then looked brand new. Unread still pin; read ones collapse behind a "Show N earlier" toggle rather than being dropped, because this bell is the only way to reopen a message thread and hiding them outright would make message history unreachable.
