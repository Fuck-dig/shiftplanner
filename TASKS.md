- [x] ~~Stop concurrent saves clobbering each other's weeks~~ (2026-08-03) - severity 6/10 (raised from 4 - it was worse than the original write-up said). syncSchedules pushed EVERY week the client held in memory and deleted every week it didn't, on every save.
